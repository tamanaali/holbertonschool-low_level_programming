# holbertonschool-low_level_programming

compile command. gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

summary:
-wall enables common compiler warnings
-werror treats warning as errors
-wextra enables additional warnings
-pedantic checks strict compliance with C standard
-str=gnu89 use the GNU C89 language standard
-o calculator Names the compiled executable calculator

How to run the code:
./calculator

Supported operators:
Addition (+)
Subtract (-)
Multiplication (*)
Division (\)


Accepted inputs:
The calculator uses integer numbers.

Limits:
Only basic mathmatical operations
