# holbertonschool-lowlevelprogramming
exercise0. this code prints the _putchar following by a line
exercise1. a function that prints the alphabet, in lowercase, followed by a new line. using prototype: void print_alphabet(void); with only using _putchar twice in the code
exercise2. a function that prints 10 times the alphabet, in lowercase, followed by a new line.
exercise3. a function that checks for lowercase character which returns 1 if c is lowercase and 0 otherwise
exercise4. a function that checks for alphabetic character, returns 1 if c is a letter, lowercase, or uppercase and returns 0 otherwise
exercise5. a function that prints the sign of a number.

Prototype: int print_sign(int n);
Returns 1 and prints + if n is greater than zero
Returns 0 and prints 0 if n is zero
Returns -1 and prints - if n is less than zero

exercise6. a function that computes the absolute value of an integer using: int _abs(int);

exercise7. a function that prints the last digit of a number.

Prototype: int print_last_digit(int);
Returns the value of the last digit

exercise8. Write a function that prints every minute of the day of Jack Bauer, starting from 00:00 to 23:59.

Prototype: void jack_bauer(void);

exercise9. Write a function that prints the 9 times table, starting with 0.

Prototype: void times_table(void);

exercise10. a function that adds two integers and returns the result.

Prototype: int add(int, int);

exercise11. Write a function that prints all integers from n to 98, followed by a new line.

Prototype: void print_to_98(int n);
Numbers must be separated by a comma, followed by a space
Numbers should be printed in order
The first printed number should be the number passed to your function
The last printed number should be 98
You are allowed to use the standard library
